Bienvenido al repositorio de la Aplicación Web para Sonrisas Saludables. Esta aplicación fue diseñada y desarrollada para mejorar la eficiencia y la experiencia tanto para los pacientes como para el personal de nuestra clínica dental.

Características

Citas en línea: Los pacientes pueden solicitar citas en línea de manera conveniente, eligiendo el dentista y el horario que mejor les convenga.

Historial de Pacientes: El personal puede acceder fácilmente al historial médico y dental completo de cada paciente, lo que permite un tratamiento más personalizado.

Recordatorios de Citas: Se envían recordatorios automáticos por correo electrónico y SMS a los pacientes antes de sus citas programadas.

Tienda en Línea: El sistema ofrece la venta de distintos productos dentales para los clientes que llegan a la clínica a ser atendidos, como usuarios nuevos.

Panel de Control para Dentistas: Los dentistas pueden acceder a un panel especializado donde pueden ver sus horarios, administrar citas y actualizar el progreso de los seguimientos de los pacientes.

Interfaz Amigable: La interfaz intuitiva hace que sea fácil para los pacientes navegar por la aplicación y realizar acciones sin dificultades.

Tecnologías Utilizadas

Frontend: HTML5, CSS3, Bootstrap.

Backend y FrontEnd: ASP.NET.

Base de Datos: Microsoft SQL Server Express para almacenar datos de pacientes, citas, entre otros.

Autenticación: Utilización de JWT (JSON Web Tokens) para la seguridad y autenticación de usuarios.

Comunicación: Integración de servicios de correo electrónico y SMS para recordatorios y comunicación con pacientes.
